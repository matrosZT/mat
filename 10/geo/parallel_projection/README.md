# Інтерактивний тренажер з геометрії (10 клас)
**Тема:** Паралельне проекціювання, його властивості. Зображення фігур у стереометрії (за підручником О.С. Істера, § 6, стор. 89–97).

## Вміст архіву
- `index.html` — повністю автономна інтерактивна вебсторінка (адаптована для ПК, планшетів та смартфонів).
- `README.md` — інструкція щодо розгортання на GitHub Pages.

## Як опублікувати на GitHub Pages
1. Створіть новий публічний репозиторій на GitHub (наприклад, `geometry-10-projection`).
2. Завантажте файл `index.html` (та `README.md`) у корінь репозиторію.
3. Перейдіть у **Settings → Pages**.
4. У розділі **Build and deployment → Source** виберіть **Deploy from a branch**, оберіть гілку `main` (папку `/ (root)`) і натисніть **Save**.
5. За 1–2 хвилини інтерактивний додаток буде доступний за посиланням виду `https://<ваш-логін>.github.io/geometry-10-projection/`.
