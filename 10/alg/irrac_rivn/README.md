# Інтерактивний тренажер: Ірраціональні рівняння (10 клас, О. С. Істер)

Готовий до розгортання на **GitHub Pages** статичний веб-додаток з адаптацією під смартфони, планшети та ПК.

## Вміст архіву
- `index.html` — головна інтерактивна сторінка (графічна симуляція ОДЗ, 2 Drag-and-Drop тренажери з підтримкою сенсорних екранів, 3 рівні задач, журнал спроб та генератор PDF-звіту).
- `assets/hero-algebra-10.jpg` — тематична ілюстрація для старшокласників (10 клас).
- `assets/favicon.svg` — векторна іконка вкладки.

## Публікація на GitHub Pages
1. Розпакуйте архів і завантажте всі файли (`index.html`, `README.md` та папку `assets/`) у корінь нового публічного репозиторію на GitHub.
2. Перейдіть у **Settings → Pages**.
3. У блоці **Build and deployment → Branch** оберіть `main` та папку `/ (root)` і натисніть **Save**.
